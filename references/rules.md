# 通用值班表验证规则

本文件只定义**通用验证规则**。禁止加入固定人员名单，也禁止加入任何针对具体个人的“某时段可排 / 不可排 / 特殊安排”。

## 使用范围

本 Skill 只能验证已有值班表。

禁止：

- 自动生成排班；
- 修改人员；
- 改写值班表；
- 修复换行；
- 调整排版；
- 创建修正版 Excel。

任何验证结果都只能以文本 / JSON 形式报告，不得回写工作簿。

## 必需输入

1. 第几周。
2. 对应周型的无课表 Excel。
3. 待验证的值班表 Excel。

缺少任意一项时，只询问缺失项，不生成替代文件。

## 周型验证

- 奇数周对应单周无课表。
- 偶数周对应双周无课表。
- 如果文件标题明确写有单周 / 双周且与周数不一致，判为 error。
- 无课表中括号周次仅表示该条目在括号指定周次生效。

## 人员来源

- 不使用仓库内置人员名单。
- 不内置任何个人例外。
- 验证涉及的人员直接来自待验证值班表。
- 可验证的人员范围来自本次无课表中出现的人员。
- 若值班表出现无课表中完全不存在的人员，标记为“无法验证”，不得自行推断其课程。

## 值班格结构

每个值班格应包含两行：

```text
第一行：1 人
第二行：1 人；允许增员时最多 2 人
```

两行之间必须是**真实 Excel 单元格内换行**。

如果内容被直接拼在同一行，即使肉眼仍能辨认，也应报告 `missing_line_break`。验证器只报告问题，不负责修复。

## 空闲验证

正常白天时段以无课表对应两节均为空闲为通过条件。

通用例外只允许定义为对所有人同时适用的规则：

- 周二下午：可按全员公休处理；
- 晚上：可按全员默认可排处理。

禁止添加任何基于姓名的个人例外。

## 增员规则

- 正常每格第二行 1 人。
- 允许增员时第二行最多 2 人。
- 1-2 节禁止增员。
- 增员时段总数不得超过所有值班时段约三分之一。
- 不因“凑满比例”而修改原值班表；只验证已有结果。

## 重复与角色

- 同一值班格不能出现重复人员。
- 同一人同一天多个时段值班：warning。
- 同一人在本周既作为第一行角色又作为第二行角色：error。
- 第一行角色每周超过 3 次：warning。
- 第二行角色每周超过 2 次：warning。

这些都是位置角色规则，不依赖任何固定姓名。

## 排版边界

本 Skill 不检查也不处理以下视觉样式：

- 字体、字号、颜色；
- 边框、填充；
- 行高、列宽；
- 合并单元格；
- 对齐方式；
- 打印设置；
- 页面布局。

“真实单元格内换行”属于值班格内容结构验证项，但发现问题后也不得修改。

## 自清理

本 Skill 保持即用即弃。

一次实际验证完成后，无论通过或不通过，都必须自动运行 `scripts/cleanup_skill.py` 删除本地 Skill 并验证删除结果。

禁止使用 `remove --all`。只删除本 Skill 的本地安装副本，不删除其他 Skill、GitHub 仓库、输入 Excel 或验证报告。
